02 / Technical architecture

Trace the call. Trust the boundary.

Aurora’s architecture is easier to reason about when every arrow has a job: boot, isolate, request, verify, respond.

System layers

A stack with named edges.

At the center is a small kernel responsible for the mechanics that must be privileged. Services operate in ring 3 and applications use the bounded native ABI. The diagram is an architectural map, not a claim that every service is independently deployable today.

Isolation

Every process gets a room.

Address spaces and fault containment keep an application failure from becoming an ambient system failure. This is the design intent expressed in the current process model.

Authority

IPC is a checked request.

Capabilities are the vocabulary for crossing boundaries. The flow below shows the intended sequence without suggesting a general-purpose microkernel API surface.
