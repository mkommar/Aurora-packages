Aurora packages

Candidate native packages for Aurora OS, built for musl-linux-amd64.

Install repository metadata

curl -fsSL https://<owner>.github.io/<repository>/apt/dists/aurora/Release

After adding this URL to an authenticated APT configuration, install with apt install aurora-make, or download a package directly from apt/pool/.

The repository is unsigned. Authenticate Release.sha256 or use a signed release policy before installing packages. APT metadata is under apt/.

Downloads and sources

See release-manifest.json for package hashes and sources/index.json for pinned source URLs, versions, hashes and licenses. Source archives are not mirrored by this generator.
