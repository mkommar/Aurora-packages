Local loop

Three honest steps.

01

Read the source truth

Start with the Aurora repository’s README, platform notes, package docs, and roadmap. Treat this package site as a map, not a replacement for source.

02

Build the documented target

Use the repository’s platform-specific build entry point and launch the BIOS/QEMU image. The guest is the primary validation surface.

03

Change one boundary

Add a focused regression, document the limitation, and update the roadmap only when the gate is actually met.
